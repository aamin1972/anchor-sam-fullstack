# Professional Anchor & Host - Full Stack Website

## Run on your PC
1. Install Node.js (LTS) if you do not already have it.
2. Open this project folder in VS Code.
3. Open Terminal in the project folder.
4. Run: `npm install`
5. Run: `npm start`
6. Open: `http://localhost:5000`

## Full-stack feature
The booking form sends data to the Express backend at POST `/api/bookings`.
Booking requests are stored locally in `data/bookings.json`.

## Replace photos
The supplied reference design is used as a temporary image source. Replace `public/reference-design.jpeg` or update image paths in `public/index.html`/`style.css` with your own event photos for the final portfolio.
